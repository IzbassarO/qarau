# A5-fix — far-layer e2e without local data

1. Generate a deterministic viewer bundle in memory under `web/e2e/fixtures/far-layer/`:
   300 object points in a unit cube, 200 far points on a larger shell, a version-1
   manifest, little-endian XYZ float32 and first-seen/observation uint16 buffers,
   RGB uint8 buffers, and a small inline frame thumbnail. No files under `data/`.
2. Serve the synthetic manifest and each asset with `page.route`. Reuse the
   existing public development viewer route and English locale setup. For the malformed
   case, replace only the far-position buffer with four bytes. Assert the warning,
   all 300 object points, and absence of the far toggle. Leave real-data skips intact.
3. Add a valid-array control that verifies 200 separate far points, the unchecked
   toggle, no warning, and successful toggling.
4. Run the far-layer spec with `QARAU_RUNS_DIR` pointing to an empty scratch directory,
   then lint, typecheck, Vitest, build, and the full Playwright suite. Put logs and
   browser/build output in the task scratch directory and stop every started server.

No new dependencies or models. Installed package metadata and licence files confirm
commercial use is allowed: Playwright and TypeScript are Apache-2.0; Three.js and
Vitest are MIT. The fixture uses only TypeScript and Node buffers.
